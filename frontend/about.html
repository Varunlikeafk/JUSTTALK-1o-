About Just Talk

Just Talk is a chat app built on GPT-OSS-20B, hosted on Groq. It is designed to show how an answer was reached, not only what the answer says.

What it does

  • Every message passes five routers in a fixed order. The first one that matches decides how it is handled.
  • When web search is on, factual and generation answers are checked against live web results.
  • Each reply comes with a reasoning trace you can open.
  • Credits rise when an answer verifies and fall when verification fails. Turning search off does not change them.

The routing and credit rules are set out on the home page.

How to use it

  1. Open the app with Open app at the top of this page.
  2. On the model page, choose Regen 1o. Regen Adaptive is not available yet.
  3. Sign in, or select Continue as guest to try it without an account.
  4. Type your question in the message box and send it with the arrow button.
  5. Use the Web Search switch in the sidebar to turn live verification on or off. Turning it off does not change your credits.
  6. Check your balance under System Credits in the sidebar. It rises when answers verify and falls when they fail.
  7. Switch model takes you back to the model page. Delete all chats clears your chat history.

Principles

Verify before you claim. Where a factual claim can be checked against a web source, the system tries to check it, and the credit balance records the result.

Show the reasoning. The trace is kept with the reply, so you can see how the answer was built and judge it yourself.

Say what is not known. Below 700 credits, careful mode asks the model to rely more on web context and to flag uncertainty.

Current status

Regen 1o is the public release. It runs on an alpha variant of the model, so answers can be wrong. Check anything important against a primary source before you act on it.

Regen Adaptive, a successor that adjusts reasoning depth to each question, is in development and not yet available.

Limits

  • Verification lowers the risk of wrong answers. It does not remove that risk.
  • Answers depend on the model and on the web results available at the time of the request.
  • Just Talk is not a substitute for professional legal, medical or financial advice.
